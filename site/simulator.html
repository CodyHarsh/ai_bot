Pip, the talking AI bot

ESP32 with a microphone, speaker and a cute OLED face. You talk, an LLM answers out loud, and the face shows how Pip feels.

Built from your Cirkit settings. INMP441 mic, MAX98357A amp + speaker and the I2C OLED on SCK=GPIO19 / SDA=GPIO21, with the I2S clock on GPIO14 and GPIO25, mic data on GPIO33 and amp data on GPIO22. Your saved sketch only drew the face. The firmware here also records, talks to the server and plays the reply.

Pressing Talk plays the whole path: the mic hears you, the ESP32 streams audio to the server, the server turns speech into text, asks the LLM, turns the answer into a voice, and the ESP32 plays it while the mouth moves. Replies in this simulator come from a small built-in rule set so it works offline.

16 emotions

Every face has glossy eyes, rosy cheeks or a small sparkle, and a gentle bob and blink. The LLM picks one with each reply. You can step through them in the real firmware with the serial commands n and p.

How the AI works

    
An ESP32 cannot run speech recognition or a language model, and it does not need to. It records your voice, a small Python server on your laptop does the thinking, and the ESP32 plays the answer. No API key is stored on the device.

    

      
flowchart LR
  M[INMP441 mic] --> E[ESP32
voice detection]
  E -->|WiFi: raw audio| S1[Server: Whisper

  S1 --> L[Claude

  L --> T[edge-tts

  T -->|WiFi: raw audio| E2[ESP32 playback]
  E2 --> A[MAX98357A + speaker]
  E2 --> O[OLED emotion face]
      

    

    

      

        
What each piece does

        
    
          
  • Voice detection (ESP32): it listens for sound above the room's noise, records until you pause, and streams the audio as it goes, so no big memory buffer is needed.
    • 
          
  • Speech to text: faster-whisper runs on the laptop CPU. Use tiny.en for speed, small.en for accuracy.
    • 
          
  • LLM: Claude Haiku answers in a fixed JSON shape: an emotion and 1 to 2 short sentences.
    • 
          
  • Text to speech: edge-tts with the child-like en-US-AnaNeural voice, converted to 16 kHz audio by ffmpeg.
    • 
          
  • Playback: the ESP32 streams the reply into the amplifier while the mouth moves with the loudness.
    • 
        

      

      

        
Modes

        
    
          
  • Buddy: cheerful chat and fun facts.
    • 
          
  • Study: calm coach, one practical tip.
    • 
          
  • Mood: empathetic pet that reacts to feelings.
    • 
          
  • Sleep: soft bedtime talk.
    • 
        

        
Switch by saying "study mode" (or buddy, mood, sleep), from the server page at http://localhost:8000, or with the serial keys 1 to 4.

      

    

    

      
Reply format the LLM must follow

      
{"emotion": "happy|excited|love|wink|joy|silly|sleepy|sad|cry|pout|surprised|thinking|shy|starry|curious",
 "text": "1 or 2 short sentences, under 160 characters"}

      
The server sends the text as speech and the emotion name in the X-Emotion header, and the ESP32 draws that face.

    

    

      
Costs and swaps

      
    
        
  • Whisper and edge-tts are free. The only paid piece is the Claude API, a few cents for a whole demo with Haiku.
    • 
        
  • No internet at the venue? Use a phone hotspot for both the laptop and the ESP32.
    • 
        
  • Want another LLM? Only the think() function in server.py changes.
